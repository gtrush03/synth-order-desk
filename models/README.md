# Speech models

Download from the whisper.cpp model repository (Hugging Face `ggerganov/whisper.cpp` and `ggml-org/whisper-vad`):

- `ggml-large-v3-turbo-q5_0.bin` — 574,041,195 bytes on the source machine
- `ggml-silero-v6.2.0.bin` — 885,098 bytes on the source machine

Or set `TRU_WHISPER_MODEL` / `TRU_WHISPER_VAD` to existing files. Models are not included in this package.
