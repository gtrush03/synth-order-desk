# Voice-note fixture

`customer-150.m4a` is a synthetic recording produced with the macOS `say` command (voice Samantha) and encoded with ffmpeg. Spoken text: "Our customer now needs 150 black T-shirts by September 18. Keep it within 1,800 dollars." Use it with the paper-clip button on /talk, or run `judge/voice-check.sh` to transcribe it locally with whisper.cpp. No human voice was recorded.
