## Reproduction and limits

The distribution includes [cloud-view source](../public-cloud/), the [host adapter](../src/tenki-browser.ts) and [guest browser script](../scripts/tenki-browser-read.mjs). It does not include credentials, a reusable session, or a ready-to-launch paid computer. Configure your own explicitly authorized existing VM and read/upload allowance. The adapter accepts only that configured session and scoped targets. It is a bounded demonstration of browser reading and file delivery, not an arbitrary browser agent.

The headed desktop uses noVNC supplied on the existing guest; the guest source HTML documents its expected module path. Tenki SDK 1.0.6 is pinned in the host distribution. See [platform details](PLATFORM.md) and [the fresh-run proof](../submission/DEMO-PROOF.json).
