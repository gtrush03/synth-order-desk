# Optional live voice

ROOT’s configured gateway returned404 for Live during the late validation, so GPT audio is not claimed working. The separate src/natural-voice.ts uses pinned edge-tts7.2.8/Microsoft Ava to speak already-confirmed reply text; it has no authority to choose or execute actions. Its portable Python executable defaults to .venv/bin/python, or TRU_NATURAL_VOICE_PYTHON. The public recording’s voice identity is stated in its own transcript.

The included src/gpt-live.ts and src/gpt-live-browser.ts adapt a separately enabled gpt-live-1/Willow voice session to the existing conversation backend. They do not replace its approval, revision or action controls. Recorded sponsor video narration is Microsoft Ava; that recording does not prove GPT audio acceptance. Current live-provider acceptance, if performed by ROOT, needs its own dated receipt.

Setup and tests do not enable this optional provider. The operator must configure a private gpt-live-allowance.json in the local conversation data directory, verify their own funding and gateway access, and supply CF_AIG_TOKEN only to the server. No gateway secret, allowance, browser SDP, private ledger or transcript is included in the distribution.

The server validates the operator allowance and verified funding before creation, and never retries ambiguous creation. Session and spending policy follow the current source and operator configuration; earlier three-minute demo limits were superseded by the user’s later policy request. Closed or unconfirmed sessions remain in its bounded local ledger. It provides explicit server hangup and recovery for known unfinished sessions after restart. Delegated user speech goes through the same conversationTurn permission boundary; replayed and stale delegations are refused. Browser/session usage events are labelled as browser evidence, not independent provider billing proof.

Session closure relies on the server and gateway hangup support. Process failure or unconfirmed hangup can leave a provider session unresolved; the application blocks new work and needs operator reconciliation. Cancellation cannot undo a backend action already executed. The 13 handed-off injected tests cover these guards plus microphone denial and closure behavior; exported selfcheck reruns the actual shipped tests without a provider call. The public static playground continues to calculate locally without a voice account.
