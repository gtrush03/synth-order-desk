Run the conversational desk on a Mac.

Use macOS 26 with Apple Intelligence and Xcode command-line tools. The full app also needs the pinned speech tools, a local Cognee API and HydraDB. Optional cloud and publication actions require your own explicitly enabled access.

Full installation & pinned versions ↗

From the isolated project source

git clone https://github.com/gtrush03/synth-order-desk.git
cd synth-order-desk
bash judge/setup.sh
bash judge/test.sh
bash judge/start.sh

Setup downloads the pinned dependencies. Keep optional provider allowances disabled until your own access is configured. Open http://127.0.0.1:7790/talk after startup.

Only want the static playground?
python3 -m http.server 8080 \
  --bind 127.0.0.1 --directory docs

Open http://127.0.0.1:8080. No voice model, cloud account or backend needed.
